## Phase 1 — Wärme (bis T-8)

Takt:

| Kanal | Frequenz |
|---|---|
| Instagram Reel | 1× / 2 Wochen (Reihenfolge: Hero → Suchprofil → Über euch → So hilft ihr → Nicht ImmoScout, dann wiederholen / Varianten) |
| Instagram Stories | 2× / Woche (kurze Reminder, Poll „kennt jemand was?“, Behind-the-scenes) |
| Facebook Feed | 1× / Monat |
| Facebook-Gruppen | 1× / Gruppe / Monat (siehe `14`) |

- [ ] Kalender in Meta Business Suite für Reels der nächsten 4 Wochen befüllt
- [ ] Story-Tage im Handy-Kalender markiert (nativ)

## Phase 2 — Druck (T-8 bis Landung)

| Kanal | Frequenz |
|---|---|
| Instagram Reel | 1× / Woche |
| Instagram Stories | 4–5× / Woche |
| Gezielte DMs | Münchner Kontakte / Vermieter-Intros — **kein** Blast |
| Facebook-Gruppen | 1× / Gruppe / Woche |

- [ ] Liste „10 Share-Bitten“ abarbeiten (Namen + Datum)
- [ ] Pin bleibt; ggf. neues Hero-Update wenn Monat sich verschiebt

## Phase 3 — Vor Ort (nach Landung)

| Kanal | Frequenz |
|---|---|
| Stories | täglich bei Besichtigungen / Tipps |
| Reels | nur bei neuem starken Clip |
| Gruppen | nur bei neuem Video oder konkretem Update |
| Pin | bleibt |

- [ ] Mietvertrag erst nach Umzugs-Landungslogik (KV/Anmeldung), nicht aus Social-Druck

## Anti-Spam (immer)

- Nicht denselben Caption-Text in ≥5 Gruppen am selben Tag.
- Keine „dringend!!!“ / Caps-Lock-Spam.
- Gruppenregeln vor dem Post lesen (`14`).

## Verify

- Phase-0-Checkboxen erledigt, bevor Phase 1 startet.
- Landungsdatum und T-8: bewusst offen, bis Flug gebucht; danach nachtragen.
