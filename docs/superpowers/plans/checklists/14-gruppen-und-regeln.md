# Facebook-Gruppen + Anti-Spam

Ziel: Wohnungsgruppen und Münchner Netzwerk-Gruppen **nativ** bespielen (kein Scheduler, kein Bot).  
Material: Hero oder passendes Stütz-Reel aus CapCut + Gruppen-Caption aus `12-reels-captions.md`.

## Vor dem Beitritt / Post

- [ ] Gruppenregeln gelesen (Pin / Dateien / „Über diese Gruppe“).
- [ ] Wohnungs-/Vermietungs-Posts erlaubt? Manche Gruppen nur „Angebot“, nicht „Suche“.
- [ ] Selbstvorstellung / Mitgliedschaftsfragen erledigt, falls verlangt.
- [ ] Video hochgeladen **aus der App**, Caption = Gruppen-Version, erster Kommentar = Suchprofil-Zeile.

## Anti-Spam-Regeln

1. **Max. 1 Post / Gruppe / Woche** in Phase 2; in Phase 1 max. 1 / Monat.
2. Nicht denselben Text am selben Tag in viele Gruppen kopieren — Caption leicht variieren oder an verschiedenen Tagen posten.
3. Keine Massen-DMs an Gruppenmitglieder.
4. Auf Kommentare antworten; keine Lösch-und-neu-posten-Schleife.
5. Bei Verwarnung / Löschung: Gruppe pausieren, nicht eskalieren.

## Verify

- Mindestens 3 Gruppen mit „Regeln gelesen“ und klarer „Suche erlaubt?“-Antwort.
- Kein Autoposter (Predis/Poppify/Buffer) für Gruppen konfiguriert.
