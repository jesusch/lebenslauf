# AI-Workflow — CapCut + Canva (+ Fallback Captions.ai)

Stack laut Spec: selbst filmen → CapCut (Schnitt + **DE-Untertitel eingebrannt**) → Canva (Statics mit eigenen Fotos) → Meta Business Suite / nativ.

## Export-Specs (alle Reels)

| Parameter | Wert |
|---|---|
| Seitenverhältnis | 9:16 |
| Auflösung | 1080 × 1920 |
| Länge | wie Skript (Hero ≤45 s) |
| Untertitel | Deutsch, **eingebrannt** (Burn-in), kein EN/PT |
| Audio | klar, Rauschen reduzieren falls nötig |
| Wasserzeichen | keines (CapCut Free ohne sichtbares Logo am Export prüfen) |

## CapCut — Schritte pro Reel

1. [ ] Besten Take aus `11-shot-liste.md` importieren.
2. [ ] Anfang/Ende trimmen; Pausen kürzen; ggf. leichte Zooms auf CTA.
3. [ ] **Automatische Untertitel** → Sprache Deutsch → Generieren.
4. [ ] Untertitel prüfen (Namen, „München“, Zahlen); Fehler korrigieren.
5. [ ] Stil: große, gut lesbare Schrift; Safe Zone (nicht hinter IG-UI unten rechts).
6. [ ] Optional: 1–2 eigene Fotos als Cutaways, keine Stock-Luxury.
7. [ ] Export 1080×1920, Dateiname z. B. `hero-muenchen.mp4`.
8. [ ] Auf dem Handy stumm ansehen — Text muss ohne Ton verständlich sein.

Wiederholen für: Hero, Suchprofil, Guter Mieter, So hilft ihr, Nicht ImmoScout.

## Canva — Statics

1. [ ] Pin-Carousel 3–5 Slides (Instagram Post), Texte aus `10-ig-fb-profil.md`.
2. [ ] Eigene Fotos einsetzen — **keine** KI-Gesichter.
3. [ ] Highlight-Cover „Wohnung“.
4. [ ] Optional: Story-Rahmen / Reminder-Template für Phase 1–2.
5. [ ] Export PNG/JPG bzw. Canva→Instagram.

## Meta Business Suite

1. [ ] Instagram + Facebook-Profil verbunden.
2. [ ] Reels / Feed für Phase 1 einplanen (Captions aus `12`, Netzwerk-Version).
3. [ ] Ersten Kommentar-Reminder: Suchprofil-Zeile manuell direkt nach Publish setzen (Suite plant den Kommentar oft nicht zuverlässig).
4. [ ] Stories und Gruppen **nicht** über Autoposter — nativ.

## Fallback: Captions.ai

Nur wenn CapCut-Deutsch unbrauchbar ist oder Teleprompter + Blickkorrektur nötig:

- Plan: Basic (~10 USD/Monat) — Captions, Denoise, Eye Contact.
- **Nicht** nutzen: AI Twin / Avatar.
- Export ebenfalls 9:16, DE-Untertitel eingebrannt.

## Bewusst nicht in dieser Pipeline

HeyGen, Synthesia, Persyn, Predis, Fliki, Poppify, Opus Clip, Hyper-Autopilot.

## Verify

- Fünf MP4s 9:16 mit eingebrannten deutschen Untertiteln.
- Mindestens ein Canva-Carousel ohne KI-Gesicht.
- Stummer Durchlauf: Botschaft verständlich.
